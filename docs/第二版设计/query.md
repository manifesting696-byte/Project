# 企业数据智能问析 Agent：四类业务场景 Query 示例

| 系统与基础知识问答 | 系统能力介绍、基本统计概念                       |
| ------------------ | ------------------------------------------------ |
| 企业业务知识查询   | 数据表、字段、表关系、指标含义和业务术语         |
| 企业数据查询与分析 | 明细查询、统计、排名、趋势、对比、关联、诊断分析 |
| 数据结果交互       | 图表生成、报告生成、指标解释、图表解释、结果解读 |

## 一、系统与基础知识问答

主要测试系统能否回答自身能力、使用方法，以及不依赖企业内部数据的基础知识问题。

| 类型 | Query 示例 |
| --- | --- |
| 系统能力介绍 | 你能帮我分析哪些企业业务数据？ |
| 系统能力介绍 | 你支持什么哪些功能？ |
| 系统使用说明 | 如果我想分析供应商交付情况，应该怎么提问？ |
| 系统使用说明 | 你能根据查询结果继续深入分析吗？ |
| 基础统计概念 | 什么是同比和环比？它们有什么区别？ |
| 基础统计概念 | 平均值和中位数有什么区别？ |
| 基础统计概念 | 什么是异常值？一般有哪些检测方法？ |
| 基础统计概念 | 相关性和因果关系有什么区别？ |

**特点：** 通常不需要执行企业数据库查询，也不必创建复杂的 Subtask DAG。Supervisor 可以直接回答。

## 二、企业业务知识查询

主要测试 Semantic Agent 能否理解企业数据表、指标定义和业务术语。

| 类型 | Query 示例 |
| --- | --- |
| 数据表查询 | 系统中有哪些与采购业务相关的数据表？ |
| 数据表查询 | `PurchaseOrders` 和 `GoodsReceipts` 分别存储什么数据？ |
| 字段解释 | `planned_quantity`、`production_quantity` 和 `rejected_quantity` 有什么区别？ |
| 字段解释 | `po_id` 和 `po_detail_id` 有什么区别？ |
| 表关系查询 | 采购订单表与收货记录表之间是如何关联的？ |
| 表关系查询 | 从供应商表能关联到哪些质量检验数据？ |
| 指标含义 | 系统中的供应商交付准时率是如何计算的？ |
| 指标含义 | 来料拒收率的计算公式是什么？使用哪些字段？ |
| 业务术语 | 什么是生产报工？它和完工入库有什么区别？ |
| 业务术语 | 什么是采购订单、收货单和入库记录？它们之间是什么关系？ |

**特点：** 主要依赖 Semantic Registry 和数据库元数据，而不是直接分析业务记录。对于系统中没有定义的指标或字段，应明确说明无法确认，不能编造。

## 三、企业数据查询与分析

这是系统的核心能力，也是最适合测试多 Agent 协作、动态规划和长链路任务的部分。

| 类型 | Query 示例 |
| --- | --- |
| 明细查询 | 查询2025年6月所有未按期交付的采购订单。 |
| 明细查询 | 列出供应商A最近三个月的全部来料检验记录。 |
| 统计分析 | 统计2025年上半年各供应商的采购订单数量和收货数量。 |
| 统计分析 | 计算各车间2025年每个月的产品合格率。 |
| 排名分析 | 找出2025年上半年交付准时率最低的五家供应商。 |
| 排名分析 | 查询今年以来废品数量最多的十种物料。 |
| 趋势分析 | 分析最近12个月的采购订单交付准时率变化趋势。 |
| 趋势分析 | 观察供应商A最近六个月的来料拒收率是否持续上升。 |
| 对比分析 | 对比供应商A和供应商B在交付及时性和来料质量方面的表现。 |
| 对比分析 | 比较2025年第一季度和第二季度各车间的生产效率。 |
| 关联分析 | 分析供应商交付延迟是否与生产计划延期存在关联。 |
| 关联分析 | 分析不同物料类别与来料拒收率之间的关系。 |
| 诊断分析 | 为什么第二季度的来料拒收率明显上升？ |
| 诊断分析 | 找出最近三个月库存积压增加的主要相关因素。 |

### 更复杂的长链路 Query

这类 Query 可以重点用于测试 Supervisor 的 Subtask DAG 规划、Agent 协作和动态重规划。

**示例 1：供应商交付与质量联合分析**

> 查询2025年上半年交付准时率最低的五家供应商，分析这些供应商的来料拒收率，并进一步判断交付表现较差的供应商是否也存在较高的质量风险。

**示例 2：生产异常诊断**

> 分析2025年第二季度各车间的生产完成情况，找出计划完成率下降最明显的车间，再结合设备故障、物料供应和废品记录调查可能原因。

**示例 3：库存与采购联合分析**

> 找出最近六个月库存积压最严重的十种物料，分析它们的采购频率、实际消耗量和生产需求，判断库存积压可能与哪些因素有关。

这类请求不应预先硬编码固定的调查路径，而是允许 Supervisor 根据查询结果决定下一步需要什么数据。

## 四、数据结果交互

这一类主要用于测试系统能否理解已有 Artifact，并基于历史数据或分析结果继续操作。

通常发生在上一轮查询或分析之后。

| 类型 | Query 示例 |
| --- | --- |
| 图表生成 | 把刚才的供应商交付准时率排名生成柱状图。 |
| 图表生成 | 将刚才的月度拒收率变化绘制成折线图。 |
| 图表修改 | 把刚才的柱状图改成横向条形图。 |
| 图表修改 | 只保留排名最低的五家供应商，并按拒收率从高到低排序。 |
| 报告生成 | 根据刚才的供应商交付和质量分析，生成一份 Markdown 报告。 |
| 报告生成 | 将前面分析出的生产异常及相关证据整理成完整报告。 |
| 指标解释 | 刚才计算的交付准时率具体使用了什么计算口径？ |
| 指标解释 | 为什么这次计算的拒收率与之前报表中的结果不同？ |
| 图表解释 | 解释一下刚才折线图中第二季度的明显波动。 |
| 图表解释 | 柱状图中的蓝色柱子代表什么？ |
| 结果解读 | 刚才的分析结果说明了什么？ |
| 结果解读 | 你提到供应商A质量风险较高，这个结论依据哪些数据？ |
| 结果追问 | 刚才排名第二的供应商是哪一家？ |
| 结果追问 | 对刚才发现的异常供应商进一步分析，看看是哪类物料导致的问题。 |

**特点：** 主要考察跨 Turn 上下文理解、Artifact 引用定位、结果复用以及 Presentation Agent 的输出能力。
