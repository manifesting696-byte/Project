# 电子供应链数据表与字段说明

## 文档范围

本文说明 `data` 目录中当前保存的16张CSV文件，内容包括各表用途、记录粒度、字段组成、当前数据规模、字段含义、取值形式、示例值，以及文件中已出现的分类和状态值。

当前文件共 **62,077条记录、143个字段位置**。字段位置按各表列数相加计算，同名字段在不同表中分别计数。记录数不包含表头。本文采用实际CSV列名，不新增或重命名字段。

CSV以文本保存数据。下文“整数”“数值”“日期文本”等表示字段的取值形式，不表示数据库已经声明的数据类型或约束。“唯一标识”描述当前文件中标识值不重复的事实。当前16个文件的全部字段均无空字符串值；该情况不等于数据库已经设置非空约束。

金额、成本、重量等字段未提供的币种、单位或计算口径，在相应字段中明确注明。示例值取自当前文件。分类值保留原始大小写和空格，分类取值表中的引号不属于实际值。
